Feels like a console, works on any site

Websites weren't designed for controllers. SofaNav reads the page the way you see it and figures out what's left, right, up and down.

✚

D-pad that makes sense

Moves to the nearest thing in that direction, keeping rows and columns lined up. Pressing back the opposite way returns where you came from.

🕹️

Free-aim stick

Point the left stick at any angle and land on what's there. The graph view draws a pie of where every angle goes.

🗂️

Cards and panels

Posts, cards and scrolling panels are single stops you can skim past. X steps inside, B steps back out.

🪟

Inside iframes too

Embedded players, chats and widgets, even from other sites, navigate as if they were part of the page.

♻️

Survives page changes

When a site swaps content or hides the button you pressed, focus lands on whatever is nearest instead of getting lost.

🎯

Keyboard-like repeat

Move once, pause, then repeat. Stick bounce and drift are filtered, so a flick moves exactly one step.

Install

Pick one. They run the same code.

Userscript

  1. Install Tampermonkey or Violentmonkey.
  2. Open the script; your manager offers to install it.
  3. Updates arrive automatically.
Install userscript

Browser extension

  1. Download and unzip.
  2. Chrome / Edge: chrome://extensions → Developer mode → Load unpacked → pick the folder.
  3. Firefox: about:debugging → Load Temporary Add-on → manifest.json.
Download extension

The extension also switches browser tabs with LB / RB.

Just try it

  1. Open any page and its developer console (F12).
  2. Paste the script and press Enter.
  3. It lasts until the page reloads.
Open the script
